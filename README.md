# DSCI 552 Homework 5

This folder contains Qiyu Niu's Homework 5 submission.

## Contents

- `notebook/Niu_Qiyu_HW5.ipynb`: completed and executed homework notebook
- `data/diagnosis.data` and `data/diagnosis.names`: Acute Inflammations data and description
- `data/communities.data` and `data/communities.names`: Communities and Crime data and description
- `requirements.txt`: Python packages used by the notebook

## Run

Install the dependencies from the repository root:

```bash
python -m pip install -r requirements.txt
```

Run Jupyter from the notebook folder so the relative data path stays correct:

```bash
cd notebook
jupyter notebook Niu_Qiyu_HW5.ipynb
```
